# 📧 AI Email Generator

An intelligent web application that generates professional, informal, and custom emails instantly using AI. This project leverages modern web technologies and the Gemini API to create well-structured emails based on user input.

---

## 🚀 Features

✨ Generate emails for multiple use cases:
- Professional emails  
- Leave requests  
- Informal emails  
- Job applications  
- PAN card requests (and more)

🧠 AI-powered content generation using Gemini API  
🎯 Dynamic prompt engineering for accurate results  
📝 Clean and structured email output (Subject, Body, Closing)  
📋 One-click copy to clipboard  
⏳ Loading animation for better user experience  
⚡ Fast and responsive UI  

---

## 🛠️ Tech Stack

### Frontend
- React.js  
- CSS 

### Backend
- Node.js  
- Express.js  

### AI Integration
- Gemini API (Google Generative AI)

---

## 📌 Usage

1. Enter the email type (e.g., leave request, job application)
2. Enter the purpose/description of the email
3. Provide optional details like degree or role  
4. Click **Generate**  
5. Copy and use the generated email  

---

## 🔐 Security Note

- API key is stored securely in backend `.env`  
- Never expose API keys in frontend
